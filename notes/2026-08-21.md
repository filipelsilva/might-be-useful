# PC Stability Testing Checklist

This checklist is for validating a new PC with an RTX 5080, Ryzen 9 9950X, and 64 GB of RAM.

## 1. Check the basics

- Update the motherboard BIOS, AMD chipset drivers, NVIDIA drivers, and operating system.
- Enable EXPO only after confirming the system is stable at stock settings.
- Confirm the RTX 5080's `12V-2x6` power connector is fully inserted and not sharply bent near the plug.
- Confirm the CPU cooler pump/fans and case airflow are working.
- Use HWiNFO64 on Windows or `lm-sensors`/`nvtop` on Linux to monitor temperatures, clocks, power, and errors.

## 2. Establish idle behavior

After 10 minutes idle, check:

- No crashes, freezes, or random application errors.
- CPU temperature is reasonable for the cooler and ambient temperature.
- GPU is not unexpectedly drawing high power.
- No WHEA hardware errors appear in Windows Event Viewer.

## 3. Test memory

- Run MemTest86 from a bootable USB for at least 4 passes, ideally overnight.
- Alternatively, use TestMem5 with a demanding profile on Windows.
- Test once with EXPO off, then again with EXPO enabled.
- Treat any memory error as a failed stability test, even if games seem fine.

## 4. Test the CPU

Use OCCT CPU and y-cruncher, or Prime95 for an especially harsh test:

- Run OCCT CPU for 30–60 minutes.
- Run y-cruncher for 30 minutes.
- Watch for errors, reboots, clock instability, and sustained thermal throttling.

The 9950X is designed to operate near its temperature limit under heavy all-core workloads, so roughly 95°C under stress is not automatically a problem. Crashes, errors, or severe throttling are the real concerns.

## 5. Test the GPU

Run:

- 3DMark Steel Nomad or Time Spy Extreme.
- 20–30 minutes of Unigine Superposition or OCCT GPU.
- Several demanding games with ray tracing enabled.

Check for artifacting, driver resets, black screens, or instability. GPU core temperatures in the 70s to low 80s °C are generally comfortable; also inspect hotspot and VRAM temperatures.

## 6. Test the whole system

After individual tests pass:

- Run OCCT's combined CPU/GPU or power test for 10–20 minutes.
- Then play demanding games for a few hours.
- Avoid leaving a combined power test running unattended, especially with a new build.

## 7. Verify performance

Compare results with reviews using the same settings:

- Cinebench 2024 for the CPU.
- 3DMark for the GPU.
- CrystalDiskMark or `fio` for storage.
- MemTest86 for RAM reliability.

A healthy system should show repeatable scores within roughly 5–10% of comparable systems, accounting for cooling, BIOS settings, drivers, and background processes.

## Stop conditions

Stop testing if you see burning smells, connector discoloration, repeated hard shutdowns, visual artifacts, or temperatures that continue rising abnormally.
